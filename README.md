# ZK-SR117: Chunked Zero-Knowledge Attestation of Fair-Lending and Calibration Controls Under SR 11-7

Companion code for the paper:

> M. N. Uddin, A. Anik, E. R. Bhuiyan, and R. T. Orpita, "Privacy-Preserving Algorithmic Accountability in Credit Markets: Chunked Zero-Knowledge Attestation of Fair-Lending and Calibration Controls Under SR 11-7," submitted to *IEEE Transactions on Computational Social Systems*, 2026. An earlier version is available as [arXiv:2608.02664](https://arxiv.org/abs/2608.02664).

A bank proves to a supervisor, with zkSNARKs generated by [EZKL](https://github.com/zkonduit/ezkl), that a committed credit model evaluated on an examiner-nonce-sampled batch of real 2022 HMDA mortgage applications satisfies two supervisory controls: the **demographic-parity gap** and the **expected calibration error (ECE)**. The supervisor verifies the proofs without seeing model weights or applicant records. Both controls are attested end-to-end at N = 32,768 applications (K = 32 chunks of n = 1,024).

## Scripts and the results they reproduce

Table and section numbers refer to the TCSS manuscript.

## Data

This repository does not redistribute HMDA microdata. To reproduce:

1. Download the 2022 Loan Application Register from the FFIEC/CFPB HMDA Data Browser: https://ffiec.cfpb.gov/data-browser/
2. Keep conventional (`loan_type = 1`), first-lien (`lien_status = 1`), home-purchase (`loan_purpose = 1`), principal-residence (`occupancy_type = 1`) applications that were originated or denied (`action_taken` ∈ {1, 3}).
3. Save as `hmda_sample.csv` in the repository root with at least these columns: `income`, `loan_amount`, `debt_to_income_ratio`, `loan_to_value_ratio`, `derived_race`, and `action_taken_binary` (1 = originated, 0 = denied).

The scripts keep single-race applicants (`derived_race` ∈ White, Black or African American, Asian, American Indian or Alaska Native, Native Hawaiian or Other Pacific Islander) and code the protected group as nonwhite = 1, White = 0. After these filters the analysis sample has 409,905 rows; the Model A holdout has 102,477.

## Installation

```bash
pip install ezkl==23.0.5 onnx onnxruntime pandas scikit-learn numpy
```

Tested with ezkl 23.0.5 and Python 3.12 on Apple Silicon.

**Trusted setup.** The production runs use `ezkl.get_srs()`, which downloads the real Powers-of-Tau ceremony file and needs outbound network access to EZKL's host. `ezkl.gen_srs()` creates a local test-only SRS; do not use it for anything beyond local testing.

## Reproducing the results

```bash
# Demographic parity (Table V)
python3 06_setup_once_clipped.py
python3 06_driver.py
python3 07_bootstrap_ci_clipped.py
python3 12_version_binding.py

# ECE (Table VII)
python3 13_ece_setup_once.py
python3 13_ece_driver.py
python3 14_ece_bootstrap_ci.py
python3 15_ece_stratified_check.py
python3 16_ece_version_binding.py

# Circuit-design comparison (Table IV)
python3 11_flatsum_real_sweep.py
python3 05_tree_sweep.py
```

The drivers are resumable: rerunning skips chunks that already finished.

Timings depend on hardware. Numerical values should match for the same data extract, nonce and constants.

## Scope and limitations

This code implements what Table III of the paper lists as implemented end-to-end. Not implemented here: the beacon-derived nonce with an in-circuit sampling proof (§VI-G), a standalone KZG commitment to the model weights (§V-B), and corpus commitment (§VI-C). The tree-reduction compile-time wall is an EZKL-specific finding and has not been tested on other proving backends. Bootstrap intervals use uniform resampling; a stratified recomputation is listed as future work in §X.
